# Deck

`rialto-deck.pdf` is the one to link. It is printed by Chromium from `deck.html`
(`node deck/print-pdf.mjs` from this directory), so it renders identically everywhere and
the chart is drawn from the same corridor numbers as the application.

`rialto-deck.pptx` is the same eleven slides as an editable file, generated by
`build-pptx.js` with pptxgenjs and validated against the OOXML schema. Regenerate either
after editing its source rather than editing the output.
